# Motorola SM7450 Kernel Source

Kernel tree for Motorola SM7450 (Snapdragon 7s Gen 2) devices, compatible with Android 16 / LineageOS 23.2 (`lineage-23.2`).

## Specifications

* **SoC:** Qualcomm SM7450 (waipio)
* **Architecture:** ARM64
* **Target Config:** `vendor/waipio_GKI.config`
